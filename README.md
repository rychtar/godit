# Git Tree

A git client docked inside the Godot editor: see what changed, stage and commit, switch branches and browse the history as a commit graph, without leaving the editor.

Every operation shells out to the system `git` binary, so there's no native extension to build and nothing platform-specific. It works anywhere `git` is on `PATH`.

## Install

1. Copy `addons/git_tree/` into your project's `addons/` folder.
2. Enable **Git Tree** under Project Settings → Plugins.
